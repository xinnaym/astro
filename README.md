# ПРАКТИЧЕСКАЯ РАБОТА № 1
### Разработка интернет-магазина одежды «ASTRO»
**г. Стерлитамак, 2024**

---

## Описание проекта
**ASTRO** — современный интернет-магазин городской технологичной одежды. 
Вся функциональность разработана на нативном стеке: **чистый HTML5, CSS3 и Vanilla JavaScript (ES6+)** без использования сторонних фреймворков (React, Vite, TypeScript), что обеспечивает мгновенную загрузку, максимальную надёжность и прозрачность архитектуры.

Все данные (каталог товаров, корзина, список желаний, профили пользователей, заказы, отзывы и сообщения обратной связи) сохраняются и синхронизируются **локально в браузере (`localStorage`)** без использования внешнего MockAPI.

---

## Архитектура и структура файлов
```
├── index.html          # Главная страница и разметка всех 9 разделов приложения
├── css/
│   └── style.css       # Полная таблица стилей, адаптивная верстка (Mobile/Tablet/Desktop), палитра Astro
├── js/
│   ├── data.js         # Базовый каталог товаров с описаниями, составом, цветами и мерками
│   ├── store.js        # Модуль работы с LocalStorage (товары, корзина, заказы, пользователи, отзывы)
│   └── app.js          # Логика SPA-роутинга по хэшу (#), фильтрация каталога, корзина, OpenStreetMap
├── server.js           # Легковесный нативный HTTP-сервер Node.js (порт 3000, без сторонних зависимостей)
├── package.json        # Конфигурация запуска проекта
└── README.md           # Документация практической работы
```

## Реализация разделов согласно Техническому заданию (9 страниц)

### 1. Главная страница (`#home`)
- Приветственное сообщение и слоган бренда: *«Одежда для движения вперёд»*.
- Промо-баннеры и акционные предложения коллекции *SS'26*.
- Блоки быстрых категорий (Женщинам, Мужчинам, Детям, Аксессуары) с прямым переходом в каталог с применённым фильтром.
- Блок ключевых технологий и особенностей (мембрана 20k/20k, футер 480 г/м², японская фурнитура YKK).
- Подборка популярных товаров с возможностью быстрого добавления в корзину и в список желаний.
- Кнопки быстрого перехода к регистрации и авторизации.

### 2. Регистрация (`#register`)
- Форма для заполнения обязательных данных: имя, фамилия, электронная почта, пароль, подтверждение пароля.
- Дополнительная информация о пользователе: дата рождения, предпочитаемый размер одежды (XS–XL) и предпочтения по стилю (Streetwear, Minimalism, Techwear, Sport).
- Валидация полей и сохранение новой учетной записи в `localStorage` с автоматическим входом.

### 3. Авторизация (`#login`)
- Форма для ввода зарегистрированного электронного адреса и пароля.
- Возможность восстановления пароля через модальное окно.
- Кнопка «Войти» для входа в систему (без демонстрационных упрощений).

### 4. Каталог товаров (`#catalog`)
- Разделение по категориям: *Женщинам*, *Мужчинам*, *Детям*, *Аксессуары*.
- Фильтры для удобного поиска:
  - по размеру (XS, S, M, L, XL);
  - по стилю (Streetwear, Minimalism, Techwear, Sport);
  - по цвету (Черный, Серый, Белый, Коралл, Лайм);
  - по диапазону цен (ползунок до 30 000 ₽).
- Живой текстовый поиск по названию и составу ткани.
- Сортировка: по новизне, по возрастанию/убыванию цены, по популярности.
- Добавление товаров в корзину и в список желаний (Wishlist) прямо из карточки.

### 5. Страница товара (`#product`)
- Подробное описание, характеристики ткани, сезонность и плотность.
- Галерея фотографий с интерактивным переключением ракурсов.
- Выбор размера и расцветки изделия.
- Модальное окно **«Таблица размеров»** с параметрами обхвата груди, талии, бёдер и рекомендациями по замерам.
- Рекомендации по деликатному уходу за одеждой.
- Блок отзывов покупателей с рейтингом и рабочая форма добавления нового отзыва.

### 6. Корзина и оформление (`#cart`)
- Полный перечень добавленных товаров с миниатюрой, выбранным размером, цветом и стоимостью.
- Изменение количества единиц товара (+/-) и удаление позиций.
- Выбор способа доставки:
  - Курьером до двери (490 ₽);
  - Пункт выдачи СДЭК (300 ₽);
  - Самовывоз из магазина Astro (Бесплатно).
- Выбор способа оплаты: СБП, банковской картой онлайн, при получении.
- Ввод адреса доставки и контактов получателя.
- Автоматический пересчёт итоговой суммы и создание заказа в истории покупок.

### 7. Личный кабинет (`#profile`)
- Просмотр и редактирование данных профиля (имя, фамилия, дата рождения, размер, стиль).
- История всех оформленных заказов с номерами, датами, составом и статусами (*«В обработке»*, *«Доставляется»*, *«Доставлен»*).
- Список желаний (Wishlist) с возможностью быстрого перевода вещей в корзину.
- Управление подпиской на новости и закрытые акции.
- Кнопка выхода из учётной записи.

### 8. Страница «О нас» (`#about`)
- История зарождения бренда Astro, миссия и ценности.
- Основные преимущества: устойчивое производство, японские мембранные ткани, анатомический крой.
- Сведения о дизайн-бюро и этапах создания коллекций (от эскизов до лабораторных испытаний).
- Ссылки на социальные сети (VKontakte, Telegram).

### 9. Страница «Контакты» (`#contacts`)
- Адрес флагманского магазина: **г. Стерлитамак, пр-кт Октября, 46**.
- Интерактивная карта на базе **OpenStreetMap (Leaflet.js)** с маркером магазина и информационным балуном.
- Телефон горячей линии, контактный email и график работы (ежедневно 10:00 – 22:00).
- Форма обратной связи для вопросов с сохранением сообщений в `localStorage`.

## Фирменный стиль и графический дизайн
- **Цветовая палитра**:
  - `Astro Lime`: `#C8F000` (фирменный акцентный цвет)
  - `Astro Coral`: `#F05C40` (вторичный акцент)
  - `Deep Black`: `#111215` (основной цвет текста и графики)
  - `Light Canvas`: `#F5F4F0` (фоновый оттенок)
  - `Border Gray`: `#E2E3E8` (деликатные границы)
- **Типографика**:
  - Заголовки: шрифт `Outfit` (геометричный гротеск)
  - Текст и элементы управления: `Plus Jakarta Sans`
  - Цены и числовые параметры: моноширинный `JetBrains Mono`
- **Адаптивность**:
  - Полная поддержка мобильных устройств (320px–480px), планшетов (768px–1024px) и широкоформатных экранов (1280px+).

## Инструкция по запуску

Проект содержит встроенный Node.js сервер, запускающий веб-приложение на порту `3000`:

```bash
# Запуск сервера
npm run dev

# Либо напрямую через node
node server.js
```

После запуска откройте в браузере: `http://localhost:3000`
